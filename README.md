# YashWebs — Interactive Birthday Website 🎂

A creative and interactive birthday website demo designed by **YashWebs**.

This project demonstrates how a traditional birthday greeting can be transformed into a fun, cinematic, and interactive web experience with animations, memories, surprises, and responsive design.

## 🌐 Live Demo

🎂 https://theyashwebs-code.github.io/YashWebs-birthday/

## ✨ Features

- 🎉 Interactive birthday experience
- 🔐 Demo password access
- ✨ Animated introduction
- 🎈 Interactive balloons
- 🎁 Animated gift experience
- 📸 Memory gallery
- 💫 Cinematic transitions
- 🎂 Interactive birthday cake
- 🎊 Confetti effects
- 💌 Birthday message section
- 📖 Interactive storytelling sections
- 📱 Fully responsive design
- 💻 Desktop and mobile support

## 🎨 Design

The website uses a modern, cinematic visual style with:

- Smooth animations
- Glassmorphism elements
- Gradient effects
- Interactive components
- Responsive layouts

The experience is designed to feel more like an interactive digital celebration than a traditional static webpage.
